# Roadmap
Near term: real World Risk inputs; API Center field mapping; remaining globe layers (conflict, shipping, energy, weather); satellite propagation. Done: SQLite recorder and scheduler, hazard/aircraft/launch/ISS globe layers.
Mid term: entity system with verified vs inferred relations; scenario simulator; historical datasets and playback; economic calendar; NVD and EDGAR.
Long term: multi-agent analyst with citations, investigations, public API with keys, plugin interface, workspaces, Postgres/PostGIS migration if scale requires it.
Each item ships only when it works against real data and is tested.
